# hilvana

Private PDF workflows from the terminal. Everything runs on your machine.

```bash
npx hilvana merge a.pdf b.docx -o both.pdf
npx hilvana sign contract.pdf --image signature.png
npx hilvana compress scan.pdf --target 2MB
npx hilvana word proposal.docx
npx hilvana run recipe.json *.pdf firma.png --dry-run
```

Spanish by default; `--lang en` for English. [Full docs](https://github.com/gethilvana/hilvana#readme) · MIT
